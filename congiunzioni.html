Voci e file audio

File m4a per il Mac

Usa le carte del filtro attuale, nello stesso ordine. In Chrome lo script viene salvato nella cartella ItalianVerbs (la scegli una volta sola); negli altri browser finisce in Download. Poi fai doppio clic su Crea_audio.command, oppure nel Terminale:

cd ~/gitdirectory/ItalianVerbs && ./Crea_audio.command

Ogni carta diventa un file: categoria, parola, significato in inglese, se regge il congiuntivo, la nota, l'esempio in italiano e la traduzione. I file finiscono in ItalianVerbs/audio-script-…/per-verbo/, più completo.m4a con tutto.
